The emitted command is macOS-specific. Its structure:

- Absolute system env clears ambient variables BEFORE starting absolute /bin/sh.
  Shell text is a `-c` ARGUMENT, not a pipe/heredoc that consumes Terminal stdin.
- Verify all three descriptors are TTYs and real/effective UID matches. Human

  alter the existing interactive shell. No configured account/cache access here.
- Check absolute UTC bounds before AND after hashing. Upper bound is the minimum
  of actual launch presence, source age, preparation/handoff expiry, plan headroom and
  token headroom; no command extends them. Need>30seconds at render time. Identical
  original inputs produce identical command text on read-only revalidation.
- Before executing interpreter/loader bytes, fixed system stat/shasum check exact
  size, owner, mode, one link and SHA256 for interpreter plus ALL18 sources and
  ALL6/16 artifacts. Reject a symlink leaf or nonregular/unreadable file. Hash
  subprocesses use /dev/null stdin; parent Terminal input is preserved.
- Clear the shell environment AGAIN immediately before Python, then pass exactly
  the frozen loader's environment and `-I -S -B`. This removes shell-added PWD,
  SHLVL and any imported configuration. Use only explicit prepare/four-argument
  capture interface with exact loader/artifact/review pins.
