# Session Prep documentation correction v7

Risk: Tier 2; reviewed clinical source wording. No schema, configuration, Scribe,
capture, provider-access or egress boundary changes.
Outcome: distinguish an erroneous recorded dose from a documented treatment
plan; retain both dated source statements and the error reason. Do not infer an
actual treatment change or no change from a recording correction alone.
Guard: only a closed two-clause correction/error form with a matching earlier
dose statement is recognized; optional explicit no-change must be preserved.
Require complete cited, dated material evidence; reject unsupported plan/change
claims through the existing fixed fidelity code and bounded fresh-source retry.
Other semantic forms remain prompt-directed; source-only tests do not establish
live-model fidelity or complete clinical entailment.
Version: v7 changes the normal artifact digest; old v6 artifacts/receipts cannot
serve as current. Generate a successor without rewriting old saved history.
Validation: isolated, secretless adapter tests with no sockets/subprocesses;
DB-backed prompt-upgrade regression retained for the normal authorized runner.
Release: independent final-head review, live unchanged Bob/contrasting sources,
then owner-approved coordinated staging. This checkpoint publishes nothing.
Recovery: restore the previous source image; immutable artifacts remain intact.
