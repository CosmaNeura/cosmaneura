## Scope and source evidence

Qualify the nine open Python findings on master
`9f6f07d35ae185e4381946f6a59554ec8c26a8d3`. The authoritative source-to-sink
report is [CodeQL analysis 2055362096](https://api.github.com/repos/CosmaNeura/cosmaneura/code-scanning/analyses/2055362096).
The following are reviewed false-positive dispositions, not acceptance of an
exploitable weakness. Findings remain open in GitHub; this PR does not dismiss
alerts, exclude paths, disable queries or add suppression comments. Any future
disposition must link the reviewed commit and this evidence. A zero-finding PR
scan alone does not demonstrate default-branch closure.

HMAC is a keyed message digest, as specified by [Python's HMAC documentation](https://docs.python.org/3.13/library/hmac.html).
[CodeQL's query guidance](https://codeql.github.com/codeql-query-help/python/py-weak-sensitive-data-hashing/)
distinguishes strong general-purpose hashing from computationally expensive
password hashing. This disposition depends on the actual random-token source
and keyed construction; it is not permission to hash human passwords this way.
